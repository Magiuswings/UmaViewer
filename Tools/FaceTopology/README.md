# 通用脸顶点网络与角色 BS 原型

## 当前额头边界修复版

855 节点原型的顶点网络一致性通过，但它继承了 1001 的额头裁边。整圈边界配准没有恢复 1003 等原脸更完整的上角，不能以“无退化面”代替外轮廓验收。当前生成链在原目标文件之后运行 `rebuild_forehead_targets.py --source ... --output 新目录`。

新链统一细分上边界的 10 条边，每条新增两个节点：全部 182 个目标使用相同的 20 个新增节点和面，最终 875 顶点 / 1,334 三角面。额头从 11 个物理边界节点扩展到 31 个，保留原始边界转角并实施精确位置约束，内部以带保留项的双调和位移平滑衔接。基模几何采用修正后的 1003，角色差分仍跟随各自原来的裁边。

独立重开和 182 个端点、546 个中间权重采样通过。另按原始额头折线验证：全部目标最大采样误差为 0.3904 毫米，1003 从约 21.317 毫米恢复到数值精度内一致。新拓扑有额外边界保真约束，必须重新统计网络成本，不能沿用旧 432,226 得分声称全局最优。`package_forehead_repair.py` 输出当前模型、数据、证据及代码包。

后续 CK3 头部导出见 [FaceCK3](../FaceCK3/README.md)：182 个完整身份端点通过 PDX IO 导出，复用现有 61 骨及共用头部动画；新增 `gene_uma_face_identity`，不复用原版脸部 key。材质转移与固定 1001 附件的限制、四组/年龄/命名约定及独立验证均在该流程说明中。原始共同网络和研究输出不写回。

## 原型与优化来源

从本机原始 meta/master 选择每个 chara_data 角色的一张基准头，优先 80、其次 00，以及 mob_data 实际使用的 face000～009。只解码这些头和依赖，不扫描躯干衣装。输入 M_Face 完整保留，皮肤壳、眼白、眼睑附片、口腔不能只按材质名字等同起来。

当前主优化对象是 M_Face 内最大几何连通的皮肤壳。173 个命名模型中 2008 的数据库名为 ST-2，实际是机器人式头模，单独存档；其余 172 张角色脸加 10 张 NPC 基础脸共 182 个对象，每个权重 1。眼部、牙齿、口腔及非主壳附片保留在 face-inputs 原始快照，暂不统一它们的动画拓扑。

距离为一致对应标签下的顶点集合、无向边集合和三角面集合的对称差数量之和，三项权重均为 1。模型坐标不进入该距离、候选网络评分或边编辑收益。对应关系的初始化使用骨骼语义、左右和局部位置，防止把眼眶节点分配到后脑；随后只接受增加共同边/三角面的匹配调整。该过程是有解剖对应约束的启发式图中位数搜索，不能宣称已证明任意顶点排列下的全局最优。

五个起点覆盖原参考、顶点数中位数、最小模型、最大模型和 NPC。每个起点都评价全部候选网络，然后尝试保持边界、连通分量和 Euler 特征的合法边翻转。再尝试保持表面结构的顶点折叠和源数据支持的边拆分，顶点预算限于实际源脸壳范围。

2026-10-10 结果：1001 的 855 顶点、1,314 三角面网络得分最低；42 次合法边翻转使总编辑计数从 439,396 降到 432,226。顶点增删搜索未找到满足约束的进一步改进。每个目标都制作成相同网络的修改副本，原输入不写回。

几何使用 ARAP 局部/整体形变、唯一边界弧长采样、法线兼容的表面目标及防翻转限步。它是在共同网络选定后进行的形态实现，不改变网络优化目标。直接最近点投影的早期试验出现聚点、退化面和额头缺口，未作为交付版本。

最终 Blender4.2 工程包含 Basis 和 182 个角色/NPC中性脸 Shape Keys。基础几何使用被选中模型的脸壳，算术平均形状仅放在隐藏参考集合中。182 个端点和 546 个中间权重采样都检查顶点数、编号、边和面相同，且无退化三角面。

这是一套共网格中性身份差分原型。人物贴图需要转移或重烘焙到共同 UV；原表情骨架、眼球/口腔组件和 CK3 导出没有在本轮统一。人类 NPC 的耳部及不同裁边仍存在较大的表面误差，例如 9007、9006；拓扑一致不能写成所有角色的面型已精确还原。targets-report.json 明确记录每个对象的采样误差和修改量，采样误差不是连续 Hausdorff 上界。

使用 Python3.12（numpy/scipy）和 Blender4.2。本机新增包、缓存、数据和模型均放在 E 盘；源码包不含游戏原始资源、数据库、解码配置或私有 seed。

典型顺序：prepare_face_dataset.py --extract → extract_face_dataset.py → optimize_face_network.py --scope skin --starts 5 --exclude-id 2008 → refine_common_network.py → build_common_face_targets.py → Blender build_face_blend_blender.py → verify_face_blend_blender.py → render_common_face_blender.py / render_face_sources_blender.py。

各命令 --help 提供路径参数。输出目录使用新的版本名；优化中断可用 --resume 从已完成起点继续。所有 .txt 说明用 UTF-8-BOM，模型以四位 ID 分目录并使用 uma_ 前缀。OBJ 和 Blender 都保留同一顶点编号及三角面数组。
